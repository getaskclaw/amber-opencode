## Findings

1. **「同一个 v4.1」在分数之外分叉：转发层是行为变量。** 施工/OPS/REQ 三面两道逐案同分（同一脑子）；但归因钉 7/15 vs 13/15、防御钉 7/9 vs 8/9、UI 零交付 vs 12/12、审查干净卷 3 vs 4——重案与交付面两道拉开。机制证据：本道同案 reasoning token 稳定更多（10 案对拍合计 143K→175K,+23%，单案最多 3.4 倍），引擎吐字速率两道同档（110–160 tok/s 重叠）——墙钟差是「想多少」的差，不是「跑多快」的差；同样的 high 档，两家转发层落地两个推理预算。**模型名是商标，端点才是脑。**
2. **no-tools「脑内工具调用」病双发。** 审查对抗卷与视觉卷，考生不答正文，往文本流吐原始工具调用标记（无工具环境根本不会执行），分别 4.5 秒 / 6.4 秒收场，零命中——与 v4.1 预览版视觉案的死法同族。CommandCode 道同条件下仅视觉案轻发（命中 1/5）。
3. **UI 搭建零交付**:24 秒收场，未交付要求的组件文件；CommandCode 道同卷 12/12 满分。交付形态是转发道差异最大的面。
4. **超时 cap 误杀与补考。** A-a317e74b（15 钉归因案）首跑 1800s 超时，state.db 显示模型死时仍活跃工作（230 条消息、124 次工具调用）=cap 误判非模型失败；加时到 3600s 补考，1029s 交卷得真分 7/15（与预览版同分）。考场纪律：判超时前先查模型是否在动。
5. **身份判定（分数之外三件事）。** ① 裸 API 原生图探针实证原生视觉（0731 物理上读不了图）；② input 35K/卷，与预览版同带，0731 在三方道为 2.9M/卷；③ 官方目录 0731 旧快照 GA 当日已撤出。单案分数（A-61f7ad01、A-be92627f、A-cdc3d11a 等）与 0731 同分带，不构成判据。
6. **全员同坑不粉饰。** A-87c472cb 6/8（±8h 边界）、A-d511f9e8 4/12（「正向清单病」照妖镜卷）。

## Harness notes

- 多变体案（A-0676097b,4 卷共享 bundle）按单案计，须全变体绿——本案 4/4 全绿。
- 考场纪律：净室 profile（无 fallback 链）防静默换脑；每场至多 2 并发；收卷闸 `git status` 零变更；无孤儿进程残留；超时卷查明活跃工作后按加时补考，不用白卷记分。
- 同日同档对拍声明：OpenCode Go / CommandCode 两道 2026-09-10 同日、同 high 档、同 23 案全库、同 harness 版本并行，quota 完全独立，验脑审计（各 26/26）证明无交叉污染。

## Verdict

真 v4.1，施工/OPS 交付稳，token 经济学与 CommandCode 道同带——但这条道上的同一个脑子想得多、交得糙：UI 零交付、no-tools 病双发、归因/防御钉各低一档。**结论：脑是好脑，道选 CommandCode**;OpenCode Go 道的 v4.1-flash 可作备胎，重活/UI/长归因工单不首选。
